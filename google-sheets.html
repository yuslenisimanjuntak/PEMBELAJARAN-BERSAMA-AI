MENGHUBUNGKAN KUIS HTML KE GOOGLE SHEETS

Belajar mengumpulkan hasil kuis siswa secara otomatis

← Kembali ke Halaman Utama

Tujuan Pembelajaran

Setelah mempelajari materi ini, guru diharapkan mampu:

  • Membuat Google Sheets untuk menyimpan nilai siswa.
  • Menggunakan Google Apps Script.
  • Menghubungkan kuis HTML dengan Google Sheets.
  • Menguji pengiriman hasil kuis siswa.

A. Mengenal Cara Kerjanya

Ketika siswa menyelesaikan kuis pada website, data berupa nama, kelas, nilai, dan jumlah jawaban benar dikirimkan ke Google Sheets melalui Google Apps Script.

Alur pengiriman data:

Website Kuis → Google Apps Script → Google Sheets → Guru melihat hasil siswa.

B. Langkah-Langkah Menghubungkan Kuis

Langkah 1. Membuat Google Sheets

  1. Buka Google Drive.
  2. Klik tombol Baru.
  3. Pilih Google Spreadsheet.
  4. Beri nama file, misalnya Hasil Kuis Matematika.
  5. Buat judul kolom pada baris pertama:
Waktu | Nama | Kelas | Nilai | Jumlah Benar

Google Sheets ini akan menjadi tempat penyimpanan hasil kuis siswa.

Langkah 2. Membuka Google Apps Script

  1. Buka Google Sheets yang sudah dibuat.
  2. Klik menu Ekstensi.
  3. Pilih Apps Script.
  4. Tab Google Apps Script akan terbuka.
  5. Hapus kode bawaan yang ada pada halaman editor.

Langkah 3. Memasukkan Kode Google Apps Script

Salin kode berikut dan tempelkan ke editor Apps Script.

  1. Klik ikon Simpan.
  2. Tunggu sampai kode tersimpan.

Langkah 4. Menerapkan sebagai Web App

  1. Klik tombol Terapkan di kanan atas.
  2. Pilih Deployment baru.
  3. Pilih jenis penerapan Aplikasi web.
  4. Pada bagian Jalankan sebagai, pilih Saya.
  5. Pada bagian Siapa yang memiliki akses, pilih Siapa saja.
  6. Klik Terapkan.
  7. Jika diminta izin, ikuti proses pemberian izin akun Google.
Perhatian: Pengaturan akses Siapa saja memungkinkan permintaan dari pengguna lain. Jangan menempatkan informasi rahasia atau data pribadi sensitif dalam spreadsheet.

Langkah 5. Menyalin URL Web App

Setelah penerapan berhasil, Google akan menampilkan URL Aplikasi Web.

  1. Salin URL yang berakhiran /exec.
  2. Simpan URL tersebut karena akan digunakan pada kode HTML kuis.

Langkah 6. Menghubungkan URL ke Kuis HTML

Buka file kuis HTML. Pada bagian JavaScript, masukkan URL Web App yang sudah disalin.

Ganti tulisan TEMPELKAN_URL_WEB_APP_DI_SINI dengan URL Web App milik masing-masing guru.

Langkah 7. Memastikan Kode Pengiriman Data

Pastikan kode JavaScript kuis memiliki bagian pengiriman data seperti berikut. Contoh ini menggunakan nama variabel yang sama dengan kode Apps Script di atas.

Catatan penting: Mode no-cors tidak memungkinkan halaman membaca jawaban dari Apps Script. Pesan permintaan pengiriman bukan bukti bahwa data sudah tersimpan. Bukti keberhasilan adalah adanya baris data baru di Google Sheets.

Langkah 8. Menguji Kuis

  1. Simpan perubahan file HTML.
  2. Buka halaman kuis melalui website.
  3. Masukkan nama dan kelas siswa.
  4. Jawab seluruh pertanyaan.
  5. Klik tombol kirim.
  6. Buka Google Sheets.
  7. Periksa apakah nama, kelas, nilai, dan jumlah jawaban benar sudah muncul.
Berhasil! Jika data siswa muncul pada baris baru di Google Sheets, kuis sudah berhasil terhubung.

C. Jika Data Tidak Masuk

  • Periksa kembali URL Web App pada file HTML.
  • Pastikan URL berakhiran /exec.
  • Periksa pengaturan akses Web App.
  • Pastikan kode Apps Script sudah disimpan.
  • Periksa menu Eksekusi di Apps Script untuk melihat apakah ada kesalahan.
  • Pastikan Google Sheets yang dibuka adalah spreadsheet yang terhubung dengan Apps Script.

D. Latihan Mandiri

  1. Buat satu Google Sheets untuk menampung hasil kuis.
  2. Buat Apps Script dan terapkan sebagai Web App.
  3. Hubungkan URL Web App ke kuis HTML.
  4. Lakukan uji coba pengiriman nilai.
  5. Pastikan hasil kuis masuk ke Google Sheets.
