MEMBUAT WEBSITE DENGAN AI DAN GITHUB

Belajar membuat website pembelajaran secara bertahap

Tujuan Pembelajaran

Setelah mempelajari materi ini, Bapak/Ibu guru diharapkan mampu:

  • Membuat repository baru di GitHub.
  • Meminta bantuan AI untuk membuat kode website.
  • Memasukkan kode HTML ke GitHub.
  • Menerbitkan website menggunakan GitHub Pages.
  • Memahami cara mengembangkan kuis dan menyimpan hasil belajar siswa.

1 Membuat Repository Website

Repository adalah tempat untuk menyimpan file dan kode website kita di GitHub.

Langkah-langkah:

  1. Buka situs https://github.com, kemudian masuk menggunakan akun GitHub.
  2. Klik tanda + di bagian kanan atas halaman GitHub.
  3. Pilih menu New repository.
  4. Masukkan nama repository, misalnya kuis-matematika.
  5. Pada bagian Add README, pilih On agar file README dibuat sejak awal.
  6. Pastikan pengaturan repository sesuai kebutuhan. Untuk latihan ini, pilih Public.
  7. Klik tombol Create repository.
Catatan: README adalah file yang dapat digunakan untuk memberikan keterangan tentang proyek website kita. Memilih On akan membuat file README.md secara otomatis.

2 Meminta AI Membuat Kode Website

Setelah repository dibuat, kita dapat meminta bantuan AI untuk membuat kode website. Kita tidak harus menguasai seluruh bahasa pemrograman terlebih dahulu.

Contohnya, kita ingin membuat website kuis matematika untuk siswa SMA.

Contoh prompt untuk AI

Salin prompt berikut, kemudian tempelkan ke ChatGPT.

Ingat: Prompt adalah perintah atau instruksi yang kita berikan kepada AI. Semakin jelas instruksinya, semakin sesuai hasil yang diharapkan.

3 Mengambil Kode dari AI

  1. Setelah AI memberikan kode, perhatikan bagian kode HTML yang ditampilkan.
  2. Klik tombol Copy pada bagian kode, jika tersedia.
  3. Jika tidak tersedia, blok seluruh kode kemudian tekan Ctrl + C.
  4. Kode tersebut sudah siap dimasukkan ke GitHub.
Tips: Pastikan seluruh kode disalin, mulai dari bagian awal sampai bagian akhir. Jangan hanya menyalin sebagian kode.

4 Membuat File index.html di GitHub

  1. Buka repository yang sudah dibuat.
  2. Klik tombol Add file.
  3. Pilih Create new file.
  4. Pada kolom nama file, ketik index.html.
  5. Tempel kode dari AI ke area editor dengan menekan Ctrl + V.
Perhatian: Nama file harus tepat index.html. Jangan sampai tertulis index.html.txt.

5 Menyimpan Kode di GitHub

  1. Setelah kode ditempel, periksa kembali apakah seluruh kode sudah masuk.
  2. Klik tombol Commit changes.
  3. Jika muncul kotak konfirmasi, isi keterangan perubahan bila diperlukan.
  4. Klik kembali Commit changes untuk menyimpan.

Setelah disimpan, file index.html akan muncul di repository.

6 Mengaktifkan GitHub Pages

GitHub Pages digunakan untuk menerbitkan file website agar dapat dibuka melalui internet.

  1. Buka repository GitHub.
  2. Klik menu Settings.
  3. Pilih menu Pages di bagian pengaturan.
  4. Pada bagian Build and deployment, pilih sumber Deploy from a branch.
  5. Pada bagian Branch, pilih main.
  6. Pada bagian folder, pilih /(root).
  7. Klik Save.
  8. Tunggu proses penerbitan website selesai.
Catatan: Jika website belum langsung muncul, tunggu beberapa saat lalu muat ulang halaman.

7 Membuka dan Membagikan Website

  1. Buka kembali menu Settings → Pages.
  2. Perhatikan alamat website yang diberikan GitHub Pages.
  3. Klik alamat tersebut untuk melihat website.
  4. Salin alamat website dan bagikan kepada siswa atau guru lain.
Website yang sudah diterbitkan dapat dibuka oleh orang lain melalui alamat tersebut, selama pengaturan aksesnya memungkinkan.

8 Bagaimana Guru Melihat Hasil Kuis Siswa?

Ketika siswa mengerjakan kuis, nilai dapat ditampilkan langsung di layar siswa. Namun, ada hal penting yang perlu dipahami.

HTML, CSS, dan JavaScript saja belum otomatis mengirimkan hasil kuis kepada guru. Hasil kuis biasa hanya tampil di perangkat siswa dan tidak otomatis tersimpan sebagai daftar nilai guru.

Agar guru dapat melihat hasil seluruh siswa, website perlu dihubungkan dengan tempat penyimpanan data.

Contoh sistem yang dapat digunakan:

  • GitHub Pages: untuk menampilkan website kuis.
  • Google Apps Script: untuk menerima dan mengirim data hasil kuis.
  • Google Sheets: untuk menyimpan nama, kelas, nilai, dan waktu pengerjaan siswa.

Jika sudah terhubung dan diuji dengan benar, guru dapat membuka Google Sheets untuk melihat hasil pengerjaan siswa.

Perlu diingat: Menghubungkan kuis dengan Google Sheets memerlukan pengaturan tambahan. Jangan membagikan akses spreadsheet kepada siswa jika spreadsheet tersebut berisi seluruh nilai siswa.

Penutup

Dengan bantuan AI dan GitHub, guru dapat mulai membuat website pembelajaran sendiri. Website tersebut dapat dikembangkan menjadi kuis, bahan ajar, media interaktif, dan berbagai kegiatan pembelajaran lainnya.

Mulailah dari proyek sederhana, kemudian kembangkan secara bertahap sesuai kebutuhan pembelajaran.
