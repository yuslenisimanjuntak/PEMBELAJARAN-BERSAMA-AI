MEMBUAT WEBSITE DENGAN AI DAN GITHUB

Belajar Membuat Website dari Ide hingga Terbit di Internet

← Kembali ke Halaman Utama

Pada materi ini, kita akan belajar membuat website dengan bantuan Artificial Intelligence (AI) dan menggunakan GitHub untuk menyimpan serta menerbitkan website tersebut.

Tujuan pembelajaran:

Setelah mempelajari materi ini, guru diharapkan mampu meminta AI membuat kode website, menyalin kode tersebut, memasukkannya ke GitHub, dan menerbitkan website menggunakan GitHub Pages.

Langkah 1: Membuat Repository Website

Repository adalah tempat untuk menyimpan file dan kode website di GitHub.

1
Masuk ke akun GitHub masing-masing.
2
Klik tombol New untuk membuat repository baru.
3
Isi nama repository, misalnya website-kuis-matematika.
4
Pilih Public agar website dapat diakses oleh orang lain.
5
Klik Create repository.

Langkah 2: Meminta AI Membuat Kode Website

Kita dapat meminta bantuan ChatGPT atau AI lainnya untuk membuat kode website. Agar hasilnya sesuai kebutuhan, kita harus memberikan instruksi atau prompt yang jelas.

Contoh prompt untuk membuat kuis matematika

Salin prompt berikut, kemudian tempelkan ke ChatGPT atau AI yang Anda gunakan.

Langkah 3: Mengambil Kode dari AI

1
Setelah prompt dikirim, AI akan membuat kode website sesuai instruksi kita.
2
Cari kotak kode yang ditampilkan AI. Biasanya kode ditandai dengan tulisan HTML atau html.
3
Klik tombol Copy atau ikon salin pada kotak kode tersebut.
4
Jika tidak ada tombol Copy, blok seluruh kode dengan mouse, lalu tekan Ctrl + C.
Ingat!

Yang kita salin adalah kode HTML, CSS, dan JavaScript dari kotak kode AI, bukan penjelasan atau percakapan AI di luar kotak kode.

Langkah 4: Membuat File index.html di GitHub

1
Buka repository yang sudah dibuat sebelumnya.
2
Klik Add file, kemudian pilih Create new file.
3
Beri nama file index.html.
4
Klik area editor kode untuk menempatkan kursor.
5
Tekan Ctrl + V untuk menempelkan kode yang sudah disalin dari AI.

Langkah 5: Menyimpan Kode ke GitHub

1
Periksa kembali apakah seluruh kode sudah masuk ke editor GitHub.
2
Klik Commit changes untuk menyimpan file.
3
Pastikan file index.html sudah terlihat di daftar repository.

Langkah 6: Mengaktifkan GitHub Pages

1
Buka menu Settings pada repository.
2
Pilih menu Pages.
3
Pada bagian sumber penerbitan, pilih branch main dan folder /(root).
4
Klik Save dan tunggu proses penerbitan website selesai.

Langkah 7: Membuka dan Membagikan Website

1
Buka kembali menu Settings → Pages.
2
Cari alamat website yang diberikan GitHub Pages.
3
Klik alamat tersebut untuk melihat hasil website.
4
Jika website sudah berjalan dengan baik, bagikan alamatnya kepada siswa, guru, atau orang lain.

Tips Penting

1. Berikan prompt yang jelas dan lengkap kepada AI.

2. Salin seluruh kode, jangan hanya sebagian.

3. Pastikan nama file adalah index.html.

4. Periksa hasil website setelah diterbitkan.

5. Jika ada kesalahan, mintalah bantuan AI untuk memperbaiki kode.

Refleksi Pembelajaran
