Langkah 1: Mengenal Website Pribadi

1
Website pribadi adalah halaman internet yang dibuat untuk memperkenalkan diri, menampilkan karya, pengalaman, dan informasi.
2
Website pribadi dapat digunakan sebagai portofolio digital, media berbagi informasi, dan tempat menampilkan hasil karya.

Langkah 2: Mengenal HTML dan CSS

1
HTML adalah bahasa untuk menyusun struktur halaman website, seperti judul, paragraf, gambar, dan tautan.
2
CSS digunakan untuk mengatur tampilan website, seperti warna, ukuran tulisan, dan tata letak.

Langkah 3: Membuat File Website

1
Buka repository GitHub Anda.
2
Klik tanda +, lalu pilih Create new file.
3
Beri nama file index.html.
4
Masukkan kode HTML untuk membuat halaman website pertama.

Langkah 4: Mendesain Website dengan CSS

1
Tambahkan CSS untuk memperindah tampilan halaman website.
2
Atur warna, jenis huruf, gambar, latar belakang, dan tata letak.

Langkah 5: Menyimpan File ke GitHub

1
Klik Commit changes untuk menyimpan file ke repository.
2
Pastikan file index.html sudah muncul di repository.

Langkah 6: Mengaktifkan GitHub Pages

1
Buka menu Settings pada repository.
2
Pilih menu Pages.
3
Pilih branch main dan folder /(root), kemudian klik Save.
4
Tunggu sampai website berhasil diterbitkan.

Langkah 7: Melihat Website Pribadi

1
Buka alamat website yang diberikan GitHub Pages.
2
Periksa tampilan website melalui browser.
3
Bagikan alamat website kepada teman, guru, atau orang lain.

Tips

Buat website pribadi dengan informasi yang menarik, seperti nama, foto, profil, pendidikan, hobi, dan karya. Mulailah dengan desain sederhana kemudian kembangkan secara bertahap.
